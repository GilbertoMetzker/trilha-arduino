# Trilha Arduino

Trilha de estudo para retomar Arduino e sistemas embarcados, atualizada até out/2026: o que mudou desde 2021, o que aprender primeiro e a ordem dos módulos.

A página principal (`index.html`) reúne:

- mudanças do ecossistema (placas, IDE e CLI, cores, PlatformIO), cada dado com seu grau de confirmação;
- versões confirmadas em páginas de release, com data;
- comparativo 2021 × 2026;
- recomendações (aprender primeiro, pode esperar, só com projeto);
- roadmap de 10 módulos, com marcação de progresso salva no navegador;
- fontes.

## Convenções

- Dados de versão e data vêm de fontes primárias (páginas de release). O que vem de fonte secundária ou não foi verificado está marcado como tal.
- A coluna 2021 do comparativo é de memória e não foi verificada.
- Node-RED, Home Assistant, MQTT, TinyML, testes e CI ainda não foram pesquisados; entram nos módulos 7 a 9.

## Atualizar a página

Edite `index.html` e faça commit na `main`. O GitHub Pages republica em um ou dois minutos.
